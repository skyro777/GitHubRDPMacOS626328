1Create a GitHub repo

Go to github.com/new and create a new public repository (any name, e.g. my-macos-rdp).

Check "Add a README file" so the repo isn't empty. Click Create repository.

Public is required for free GitHub Actions minutes (macOS runners cost 10x Linux, so private repos need billing).

2Add 3 secrets

Go to your repo: Settings → Secrets and variables → Actions → New repository secret

Add these 3 secrets:

Secret nameValueWhere to get it
TS_AUTHKEY Tailscale auth key Tailscale → Settings → Keys → Generate auth key
Check: Reusable + Ephemeral
RUSTDESK_PASSWORD Any strong password Make one up — this is the password you type into the RustDesk client
MAC_USER_PASSWORD Any strong password Make one up — this is the macOS admin user password (for TCC prompts)

3Create the workflow file

In your repo, create a file at this exact path:

.github/workflows/mac-remote.yml

Click the button below to copy the entire workflow, then paste it into that file:

.github/workflows/mac-remote.yml
name: macOS 15 Remote Control

on:
  workflow_dispatch:
    inputs:
      hold_minutes:
        description: "Session duration in minutes. 0 = no limit. Default: 0"
        required: false
        default: "0"
      remote_method:
        description: "rustdesk or moonlight"
        type: choice
        default: rustdesk
        options: [rustdesk, moonlight]

jobs:
  remote-control:
    runs-on: macos-15
    timeout-minutes: 360
    env:
      HOLD_MINUTES: ${{ inputs.hold_minutes }}
      REMOTE_METHOD: ${{ inputs.remote_method }}
      SUNSHINE_USER: ${{ secrets.SUNSHINE_USER }}
      SUNSHINE_PASS: ${{ secrets.SUNSHINE_PASS }}
      TS_AUTHKEY: ${{ secrets.TS_AUTHKEY }}
      RUSTDESK_PASSWORD: ${{ secrets.RUSTDESK_PASSWORD }}
      MAC_USER_PASSWORD: ${{ secrets.MAC_USER_PASSWORD }}
      MAC_USER: ${{ secrets.MAC_USER }}
      SCRIPT_CDN: "https://macos-file-page.needfile5444.workers.dev"
    steps:
      - name: Checkout repo
        uses: actions/checkout@v4

      - name: Fetch all scripts from CDN
        run: |
          echo "Fetching scripts from ${{ env.SCRIPT_CDN }}..."
          mkdir -p apple-project
          cd apple-project
          for f in mac_lib.sh mac_00_setup_user.sh mac_01_install_tailscale.sh \
                   mac_02_install_rustdesk.sh mac_03_grant_permissions.sh \
                   mac_04_start_rustdesk.sh mac_05_hold_session.sh \
                   mac_06_sunshine.sh mac_grant_tcc.py; do
            echo "  Fetching $f..."
            curl -fsSL "${{ env.SCRIPT_CDN }}/$f" -o "$f"
            chmod +x "$f"
            echo "  OK ($(wc -c < "$f") bytes)"
          done
          echo "All scripts fetched."

      - name: Step 00 - provision helper admin user
        run: bash apple-project/mac_00_setup_user.sh

      - name: Step 01 - install + connect Tailscale
        run: bash apple-project/mac_01_install_tailscale.sh

      - name: Step 02 - install + configure RustDesk
        run: bash apple-project/mac_02_install_rustdesk.sh

      - name: Step 03 - grant TCC permissions
        run: bash apple-project/mac_03_grant_permissions.sh

      - name: Step 04 - verify RustDesk + print connection info
        run: bash apple-project/mac_04_start_rustdesk.sh

      - name: Step 05 - install Sunshine (moonlight only)
        if: ${{ inputs.remote_method == 'moonlight' }}
        run: bash apple-project/mac_06_sunshine.sh

      - name: Step 06 - hold session open
        run: bash apple-project/mac_05_hold_session.sh

The workflow fetches all 9 scripts from a CDN at runtime — no need to clone or fork any repo. Just this one file.

4Run the workflow

Go to your repo: Actions → macOS 15 Remote Control → Run workflow

Choose session duration (0 = no limit, GitHub caps at 6 hours) and method (rustdesk or moonlight).

Click Run workflow and wait ~3 minutes.

5Connect

When the job log shows "WEB REMOTE IS READY" with a URL like:

http://100.x.x.x:8080

Open that URL in your browser. You can now:

  • Click on the screenshot to click that position on the Mac
  • Type text in the text box and click "Type"
  • Open settings panes with the shortcut buttons
  • Type password with the dedicated button
Install Tailscale on your device first and sign into the same tailnet as your auth key. The web remote URL is only reachable over the Tailscale VPN. Download Tailscale

How it works

The workflow runs on a GitHub-hosted macOS 15 (Sequoia) runner — a real Mac VM with Apple Silicon.

It installs Tailscale (WireGuard VPN, connects the runner to your devices), RustDesk (remote desktop, direct-IP mode, no relay), and grants TCC permissions (Screen Recording, Accessibility, Input Monitoring).

A web remote server runs on port 8080 — accessible via your Tailscale IP. It uses screencapture (not VNC, so no black screen) + cliclick for clicking.

Troubleshooting

Job fails instantly: Make sure your repo is public (private repos need billing for macOS minutes).

Can't connect to web remote: Install Tailscale on your device, sign in to the same tailnet.

Web remote shows old screen: Click "Refresh" button to take a new screenshot.

RustDesk not listening: Grant TCC permissions first via the web remote (click Configure, toggle, type password).

Tailscale node not found: The auth key must be "reusable" + "ephemeral".
